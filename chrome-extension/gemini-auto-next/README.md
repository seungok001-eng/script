# Gemini 자동 다음 단계 (크롬 확장)

Gemini(**Gems 포함**, gemini.google.com) 대화에서 **응답이 끝날 때마다 "다음 단계 진행해"를 지정한 횟수만큼 자동 전송**하는 확장입니다.

## 설치 (개발자 모드)
1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 이 폴더(`chrome-extension/gemini-auto-next`) 선택

## 사용법
1. gemini.google.com에서 작업할 **대화(또는 Gem)** 를 연다.
2. 확장 아이콘 클릭 → **자동 전송 횟수** 입력(예: 4) → **시작**.
3. Gemini 응답이 끝날 때마다 "다음 단계 진행해"가 자동 입력·전송된다.
4. 지정 횟수가 끝나면 자동 종료. 화면 우하단 배지의 **중지** 버튼으로 언제든 멈출 수 있다.

## 동작 방식
- 생성 중에는 '중지(Stop)' 버튼이 떠 있고, 끝나면 사라지는 것을 감지해 "응답 완료"를 판단합니다.
- 완료되면 입력창(Quill `.ql-editor`)에 텍스트를 넣고 전송 버튼을 클릭합니다.

## 주의·한계
- **gemini.google.com 웹**에서만 동작합니다.
- Gemini의 화면 구조(셀렉터)가 바뀌면 `content.js`의 버튼/입력창 탐지 로직을 조정해야 할 수 있습니다.
- 같은 대화에 계속 누적되므로 대화가 길어지면 후반 품질이 떨어질 수 있습니다.
- 웹 UI 자동 조작은 서비스 약관에 저촉될 수 있으니 **본인 책임 하에** 사용하세요.
