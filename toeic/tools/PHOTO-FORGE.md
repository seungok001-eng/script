# 토익 사진 공방 사용법 (Part 1 사진 150장)

교재 공방을 복사해 토익 Part 1 사진 전용으로 고친 프로그램입니다. 문제 150개(`data/part1.json`, 연습·하프 모의고사 120 + 정규 모의고사 30)마다 사진 한 장씩, **구글 플로우**로 만들고 검수해서 앱(`app/images/p1`)에 넣습니다.
쓰는 확장 프로그램은 **교재 공방 Flow Bridge** 그대로입니다 (새로 설치할 것 없음). 서버 주소만 `8767` 로 바꿉니다.

## 0. 처음 한 번: 코드 받기

명령 프롬프트(cmd)를 열고:

```
cd C:\
git clone -b claude/eager-hypatia-6qxuqf https://github.com/seungok001-eng/script.git
```

이미 받아 둔 적이 있으면 그 폴더에서 `git pull` 만 하면 됩니다.

## 1. 공방 켜기

1. `C:\script\toeic\tools\photo-forge.cmd` 를 더블클릭합니다.
   - 처음 실행하면 바탕화면에 **토익 사진 공방** 바로가기가 생깁니다. 다음부터는 그걸 누르면 됩니다.
   - 검은 창이 뜨고 크롬에 `http://localhost:8767` 이 열립니다. **검은 창은 끝날 때까지 닫지 마세요** (닫으면 공방이 꺼집니다).
2. 왼쪽에 **Part 1 사진 0/150** 이 보이면 정상입니다.

> 교재 공방(8766)과 동시에 켜도 됩니다. 단, 확장 프로그램은 한 번에 한 공방만 연결됩니다.

## 2. 플로우 연결

1. 크롬에서 구글 플로우(labs.google/fx 또는 flow.google.com)에 로그인해서 탭을 하나 열어 둡니다 (교재 공방 때와 같게).
2. 크롬 오른쪽 위 퍼즐 아이콘 → **교재 공방 Flow Bridge** 를 누릅니다.
3. **교재 공방 서버 주소** 칸을 `http://localhost:8767` 로 고치고 **자동화 시작**.
4. 공방 화면 왼쪽 위가 **● 확장: 연결됨** (초록 점)으로 바뀌면 됩니다.

> 나중에 교재 공방으로 돌아갈 때는 이 칸을 다시 `http://localhost:8766` 으로 바꾸세요.

## 3. 생성

- 처음에는 **왼쪽 아래 묶음 → 1묶음** 을 고르고, 위쪽 **그림 없는 것 자동 생성** 을 누릅니다 (30장씩 나눠서 하면 검수가 편합니다).
- 확장이 한 번에 4장씩 플로우에 보내고, 끝나면 카드에 사진이 나타나며 상태가 **검수** 로 바뀝니다.
- 시험 삼아 한 장만 해 보려면 카드의 **자동 생성** 버튼을 누르세요.
- 플로우 화면에서 직접 만든 사진을 카드의 **그림 끌어다 놓기** 칸에 끌어다 놓아도 됩니다.

## 4. 검수 (가장 중요)

카드마다 이렇게 보입니다:

- 회색 글: 어떤 장면이어야 하는지 (한국어)
- **✔ 초록**: 사진에 **반드시 보여야 할 것**
- **✘ 빨강**: 사진에 **보이면 안 되는 것**
- 아래 (A)~(D): 실제 문제 보기. **초록 굵은 글씨가 정답**

사진을 눌러 크게 보고:

| 이러면 | 누를 것 |
|---|---|
| ✔ 가 다 보이고 ✘ 가 하나도 없다. 정답 문장이 분명히 맞고 나머지 셋은 분명히 틀리다 | **승인** |
| ✔ 중 하나라도 안 보이거나, ✘ 중 하나라도 보인다 | **버리기** → **자동 생성** (다시 만듦) |
| 글자·로고가 읽힌다, 손가락·얼굴이 이상하다, 사진 같지 않고 그림 같다 | **버리기** → **자동 생성** |
| 세 번 해도 계속 같은 문제 | 카드의 **프롬프트** 를 열어 고치거나, 저에게 문제 번호(p1-0xx)만 알려 주세요. 문제와 프롬프트를 고쳐 드립니다 |

- 잘 나온 것만 모였다면 위쪽 **검수 중 N개 전부 승인** 으로 한 번에 승인해도 됩니다 (꼭 한 번씩 보고 나서).
- 시험 실제 사진처럼 **평범한 일상 사진**이면 충분합니다. 예쁠 필요는 없고, **정답만 분명하면 됩니다**.

## 5. 앱에 넣고 올리기

1. 위쪽 **승인된 것 전부 앱에 넣기** 를 누릅니다 → `toeic\app\images\p1\p1-001.webp …` (960×720, 장당 약 100KB) 가 생깁니다.
2. 150장 다 끝나지 않아도 됩니다. 30장씩 올려 주셔도 됩니다.
3. 명령 프롬프트에서:

```
cd C:\script
git add toeic/app/images/p1
git commit -m "Part 1 사진 추가"
git push
```

그다음 저에게 "사진 올렸어" 라고 말해 주세요. 제가 사진을 하나씩 보고 문제와 맞는지 다시 확인한 뒤, Part 1 음성(Kokoro)·문제 화면·모의고사 연결을 합니다.

## 참고

- 원본·검수용 사진은 `toeic\art-src\forge` 에 쌓이고 저장소에는 올라가지 않습니다 (용량 때문에).
- 공방을 껐다 켜도 진행 상태(승인·검수)는 그대로 남습니다.
- 생성기는 플로우만 씁니다 (교재 공방과 같은 결정). 플로우 구독 크레딧이 듭니다.
