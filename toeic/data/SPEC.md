# TOEIC VOCA 단어 데이터 규격 (day-XX.json)

대상: 토익을 준비하는 한국 성인. 모든 영어 문장은 실제 토익(LC/RC)에 나올 법한 비즈니스·일상 업무 맥락.
파일: `toeic/data/days/day-XX.json` (XX = 01~30), UTF-8, JSON 배열. plan.json의 해당 Day 단어 40개를 **같은 순서, 같은 철자**로 모두 포함.

```json
{
  "w": "applicant",
  "pos": "n",
  "m": ["지원자", "신청자"],
  "tier": 1,
  "parts": [5, 7],
  "ex": "All *applicants* must submit two letters of reference by Friday.",
  "exKo": "모든 지원자는 금요일까지 추천서 두 통을 제출해야 합니다.",
  "col": [{"e": "qualified applicants", "k": "자격을 갖춘 지원자"}, {"e": "applicants for the position", "k": "그 직책의 지원자"}],
  "der": [{"w": "apply", "pos": "v", "m": "지원하다, 적용하다"}, {"w": "application", "pos": "n", "m": "지원(서), 적용"}],
  "para": ["candidate"],
  "ant": "",
  "tip": "사람명사 applicant와 사물명사 application을 구분하는 Part 5 문제가 자주 나온다.",
  "q": {"s": "Only ------- with at least three years of sales experience will be invited to an interview.", "o": ["applicants", "applications", "apply", "applied"], "a": 0, "k": "with 이하의 경력을 가진 '사람'이 면접에 초대되므로 사람명사 applicants가 정답."}
}
```

필드 규칙
- `w`: plan.json 철자 그대로 (구·숙어도 그대로. 예: "fill a position", "be subject to").
- `pos`: n / v / adj / adv / phr(구·숙어) / prep / conj 중 하나. 대표 품사 하나.
- `m`: 한국어 뜻 1~3개. **토익에서 쓰이는 뜻을 먼저**(예: raise → "인상, 임금 인상" 먼저). 자연스러운 사전식 표현. 동사는 "~하다", 형용사는 "~한/~인".
- `tier`: 1 = 기본(목표 600~650점에 필수, 기초 비즈니스 어휘), 2 = 핵심(700~800점), 3 = 고득점(850~900+점, 어렵거나 덜 흔한 어휘). 한 Day 안에서 대략 1:40%, 2:35%, 3:25%가 되도록 실제 난이도대로.
- `parts`: 이 단어가 특히 자주 나오는 토익 파트 번호 배열(1~7). 대부분 [5,6,7] 중 일부, 듣기 빈출이면 2,3,4 포함, 사진 묘사형이면 1.
- `ex`: 토익식 예문 1개, 8~20단어, 자연스럽고 정확한 현대 비즈니스 영어. 표제어(활용형 가능)를 문장에 정확히 한 번 넣고 그 부분만 `*...*`로 감싼다. 구·숙어는 구 전체를 감싼다(중간에 목적어가 끼면 실제 쓰인 연속 구간만, 예: "*filled* the *position*"처럼 두 군데도 허용). 따옴표는 곧은 따옴표 ' 만 사용, 이모지·특수기호 금지. 숫자는 써도 되지만 과하지 않게.
- `exKo`: 예문의 자연스러운 한국어 번역(존댓말 아닌 평서체 "~한다/~했다" 또는 공지문은 "~합니다" 허용, 한 파일 안에서 일관되게).
- `col`: 토익 빈출 연어(콜로케이션) 1~3개, 각각 영어 `e` + 한국어 `k`. 전치사 짝(be eligible for 등)이 있으면 반드시 포함.
- `der`: 파생어·관련 품사 0~3개(`w`,`pos`,`m`). 표제어와 같은 단어 금지. Part 5 품사 문제에 실제로 나오는 형태 우선.
- `para`: Part 7 패러프레이징(동의 표현) 1~3개, 영어 문자열. 문맥상 바꿔 쓸 수 있는 것만. 없으면 [].
- `ant`: 대표 반의어 하나 또는 "".
- `tip`: 한국어 1~2문장 '출제 포인트'. 품사 자리, 전치사 짝, 혼동어, 가산/불가산, 자동사/타동사, 듣기 함정 등 실전에 쓸 정보. 일반론("자주 나온다")만 쓰지 말 것.
- `q`: 이 단어를 정답으로 하는 **토익 Part 5 스타일 문제** 1개.
  - `s`: 예문과 **다른** 문장, 빈칸은 하이픈 7개 `-------` 정확히 하나.
  - `o`: 보기 4개(모두 서로 다름). 유형은 단어마다 적절히: 품사/파생어 문제(apply/applicant/application/applied), 어휘 문제(비슷한 품사의 다른 단어들), 전치사·숙어 문제 등. 정답은 표제어 또는 그 활용형.
  - `a`: 정답 인덱스 0~3 (정답 위치를 골고루 섞을 것, 항상 0 금지).
  - `k`: 한국어 해설 1~2문장(왜 정답인지 + 오답 함정).
  - 정답이 문법·의미상 유일해야 한다. 다른 보기도 정답이 될 수 있으면 안 된다.

품질 기준: 상용 앱에 그대로 출시된다. 오탈자·어색한 번역·틀린 문법·모호한 문제는 결함이다. 다 쓰고 나면 스스로 한 번 더 전체를 검토하고 고칠 것.
